# 受控 AI 配置与用量

本阶段提供 B01～B09 的受控模型实现。未配置模型、个人候选或预算时，AI 不开放；手工理财、已有数据及行情仍可使用。默认不会导入环境中的模型密钥，也不会使用 Keychain 或 CLI 回退。

更新到本阶段代码后，需要用原来的 `LICAI_DATA_DIR` 重启后端。`python run.py` 不会自动重载 Python 代码，仅构建前端会造成新页面访问旧接口。重启后确认实际服务的 OpenAPI 包含 `/api/models` 的 GET/PUT；模型表由启动初始化创建，保存后应在服务列表及场景下拉选项出现，刷新后仍保留。

## 配置顺序

1. 管理员登录，在设置中的「模型服务」新增模型。模型标识在本实例内唯一，实际模型 ID 由管理员按厂商账号可用型号填写，不预设固定型号。
2. 云端服务填写 HTTPS 基础地址、API Key、价格、汇率和开放能力。单价单位为原币／百万 Token，预算单位为人民币；0 是明确零价，留空不是零价。一小时缓存若返回用量却没有配置单价，会保留待核实占用。
3. 在「用量与预算」配置全局及各用户的日、月额度。0 为无额度，留空为未配置；用户调用需要四项均为正且有剩余额度。额度修改不清空已用费用。
4. 管理员核对当前费用及预算后，填写依据并允许受控云端调用；初次安装和恢复后默认暂停云端。仍有在途或待核实记录时不能确认。
5. 用户在「我的 AI 设置」按场景选择主模型及有序备用，最多三项。管理员不能替其他用户设置候选。停用模型保留用户的原选择，不自动指定替代。
6. 能力测试由管理员明确点击，每次云端测试可能计费，只占全局额度；测试使用固定合成输入，不读取用户问答。按文本、工具、图像、结构化输出分别记录配置版本对应的结果。

管理员配置的能力与真实实测记录分开展示。修改配置会生成新版本，旧版本测试不能当作新版本通过。所有目标协议均有离线测试；真实型号、账号、地域及具体 Ollama 安装的结果仍须单独实测，不能把代码支持当作厂商可用性承诺。

DeepSeek 的表单按厂商口径仅显示缓存命中输入、缓存未命中输入和输出三项单价，不要求填写缓存写入及一小时缓存写入。内部统一计量将缓存命中输入映射为 `cache_read`，未命中输入映射为 `input`；不适用的写入价格保存为零／空值。当前仍是一组固定单价，尚未接入高峰／空闲分时定价；需保守估算时手动使用高峰价，空闲时段可能高估费用。

## 停用、启用与删除模型服务

管理员可直接在模型服务列表点击「停用」或「启用」，无需进入编辑表单。停用保留原配置及用户选择，阻止后续模型请求；已经发出的请求仍按实际返回用量结算。重新启用前仍需满足凭证、价格及协议配置要求。

删除前须先停用，再点击「删除」并确认。删除仅移除本应用的服务配置和凭证，不删除 Ollama 的模型文件，也不删除历史调用、预算占用、待核实费用或汇总。个人原选择保留并显示为失效，不自动换成其他模型。已删除标识不可复用，避免旧选择或排队任务绑定到新服务；可用新标识重新添加服务。

管理接口仅管理员可用：`PATCH /api/models/{identifier}` 接收 `enabled` 与 `expected_version`，`DELETE /api/models/{identifier}` 接收 `expected_version`。版本冲突返回 409；删除仍开放的服务也返回 409。操作均保留管理审计记录。


## 基础地址和协议

切换协议时，表单自动填入下表对应的默认基础地址，仍可手动修改；打开已有模型的编辑表单时保留其已保存地址。Qwen 默认北京地域，自定义 OpenAI 兼容协议留空，按账号地域或服务商要求填写。此操作只修改待保存表单，不发起模型调用。

| 协议 | 基础地址示例 | 应用追加路径 |
|---|---|---|
| Ollama | `http://localhost:11434`；Docker 使用 `http://host.docker.internal:11434` | `/api/show` 验证本地模型、`/api/chat` 推理 |
| Anthropic | `https://api.anthropic.com` | `/v1/messages` |
| OpenAI Responses | `https://api.openai.com` | `/v1/responses` |
| DeepSeek | `https://api.deepseek.com` | `/chat/completions` |
| 通义千问兼容模式 | 默认北京 `https://dashscope.aliyuncs.com/compatible-mode/v1`；其他地域按账号修改 | `/chat/completions` |
| Gemini 原生 | `https://generativelanguage.googleapis.com` | `/v1beta/models/{model}:generateContent` |
| 自定义 OpenAI 兼容 | 管理员指定的 HTTPS 基础端点，包含服务要求的版本前缀 | `/chat/completions` |

默认地址依据：[OpenAI Responses](https://developers.openai.com/api/reference/resources/responses/methods/create)、[Claude API](https://platform.claude.com/docs/en/api/overview)、[DeepSeek API](https://api-docs.deepseek.com/)、[Qwen 地域地址](https://help.aliyun.com/zh/model-studio/base-url)、[Gemini generateContent](https://ai.google.dev/api/generate-content)、[Ollama 本机地址](https://github.com/ollama/ollama/blob/main/docs/faq.mdx)。基础地址的路径前缀按本项目适配器配套填写，不直接复制其他 SDK 的示例前缀。

自定义接入必须显式选协议，不通过换域名猜测协议。端点不允许用户名、密码、查询串或片段；云端不能解析为本机或内网地址，重定向不自动跟随。只从管理员指定的模型配置读取凭证。凭证包含在本机数据库及备份中，沿用已有文件权限与备份保护。

仅本地只允许本机 Ollama 或 Docker 的宿主机入口；模型名称含 cloud 或 `/api/show` 表明远程来源时拒绝推理。局域网其他推理服务器不当作本机。Ollama 模型／版本支持哪些能力须逐项测试，不支持时仅尝试用户选择的合格候选。

## 执行和取消

- 所有场景均经过统一运行时，每次物理推理请求、重试及下一轮工具调用都重查账号、模式、候选、能力、代际和预算。厂商适配器不自行重试，不启用厂商内置付费联网工具；独立搜索待 C 阶段。
- 本地队列默认全局并发为 1（管理员可调整为 1～8，不抢占在途），每用户最多 2 个等待、总容量 20，等待最多 5 分钟；交互优先、用户轮转，每连续五次交互后给已等待至少 2 分钟的后台执行机会。排队超时不会擅自转云端，不抢占正在推理的请求。
- 重复提交相同的活动问答复用任务。关闭页面或普通退出只停止跟看；明确取消后不新增模型、工具或备用。停用和凭据版本变化会阻止旧任务继续。
- 问答备用从原始问题生成独立完整版本，失败部分标记未完成并保留；不会把两家模型的半段混成一份完整答案。达到输出上限不会自动放大 Token 预算。
- 在途 HTTP 请求受到读超时约束，无法承诺取消时厂商不计费。取消后的迟到用量仍结算，结果不得恢复业务终态；重启只标记中断，不自动计费重跑。

## 费用与恢复

一次 SQLite 事务同时检查及预留全局／个人的日月额度。按北京时间切分周期，迟到结果结算到发起周期；价格、汇率和原币费用随尝试保存，不回算。输入预算使用序列化请求 UTF-8 字节和协议余量作保守上界，图像按配置的上下文上限预留；输入价取普通／缓存最高适用单价，费用再留 10% 安全量。估算仍不构成厂商账单承诺。

已知最终用量只结算一次。超时、连接结果不明、流缺终止事件或用量缺失时保留占用，并暂停同一端点的云端请求；不会按 0 释放。只有明确尚未计费的失败可有限重试，每次仍独立建账。实际费用超过预留时照实入账并暂停服务，管理员核对后才能继续。

普通用户查看本人调用；管理员查看全局／用户计量元数据，不通过用量接口查看提示词、回答或工具正文。默认 80% 预警、100% 停止，周期和阈值持久去重；明细默认七天，管理员可调整保留期和低于 100% 的预警。清理展示明细不清除财务最小依据、月汇总和未结算占用；备份可能仍含历史记录。

恢复时合并恢复前后账本，按稳定 UUID 匹配用户费用及仅本地安全偏好；在途云端尝试转待核实，保持云端暂停。管理员根据账单在「人工核对」填写用量及理由，重新核对额度后再确认开放。不能因为恢复了更早的数据库就直接重新使用旧余额。

## 官方协议核对依据

以下依据用于协议字段核对，离线响应均为按公开合同构造的合成数据，没有抓取真实用户或付费请求：

- [OpenAI Responses](https://platform.openai.com/docs/api-reference/responses)：原生调用与输入、输出、缓存／推理细分。
- [Anthropic Messages](https://platform.claude.com/docs/en/api/messages) 与 [缓存输入口径](https://platform.claude.com/docs/en/api/rate-limits)：普通输入、缓存读写分列，推理包含在输出总量。
- [DeepSeek Thinking Mode](https://api-docs.deepseek.com/guides/thinking_mode/)：工具轮次保留 `reasoning_content`，不能当普通正文丢弃。
- [通义千问 API](https://help.aliyun.com/zh/model-studio/qwen-api-reference/)：兼容模式及地域端点，实际能力须按型号验证。
- [Gemini generateContent](https://ai.google.dev/api/generate-content)：原生消息、用量及工具签名。
- [Ollama 官方 API 合同](https://github.com/ollama/ollama/blob/main/docs/openapi.yaml)：本地推理与远程模型元信息。

官方网页和 API 会变化。当前没有真实厂商账号／型号联调证据；文档中的示例地址不代表已配置凭证、已开放预算或已部署日常环境。
