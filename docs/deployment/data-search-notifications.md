# 公共数据、免费搜索与我的通知

C 部分沿用现有 FastAPI、React 与 SQLite，无新增运行依赖。管理员在「设置 → 管理：数据中心」管理公共来源；每个用户在「我的通知」管理本人渠道，在设置中独立开关在线搜索。现阶段仅启用 DeepSeek 与本地 Ollama，模型服务配置不因 C 改变。

## 来源与数据质量

- A/H/美股票实时价支持新浪与腾讯两个独立适配器，分别设置顺序或停用；新浪港股 `rt_hk`/`hk` 是同一供应商，不算独立备用。腾讯港美股成交量/成交额尚未完成实测，不猜测单位，返回空值；实际覆盖须逐市场联调。
- A 股日 K 单独配置东方财富／腾讯顺序，固定前复权。请求失败只能使用有前复权来源记录的旧缓存，不混入新浪不复权序列；升级前没有复权依据的旧缓存不作为可信前复权缓存。港美股沿用既有独立日 K 路径。
- 资讯按勾选来源并行聚合，一源失败不阻塞其他源；同标题合并后保留各原媒体、链接及时间，不把采集器当原媒体。
- 报价带 `source_id/source_at/fetched_at/currency/unit/market_state/quality/stale_reason`；获取时间不代替源时间。交易中落后 120 秒标延迟、300 秒标旧值；休市核对最近交易时段，旧周报价不能冒充最近收盘。
- 主备失败保留进程内最后成功价并标旧值，首次缺价返回 `price=null`。进程重启后若没有可靠报价则标缺失，不捏造最近成功时间。
- 持仓和实时推送缺价不生成零市值或 -100% 收益；顶部展示股票估值覆盖。包含缺价／不可信报价的组合不写入完整日估值快照。AI 报价输入继承时效限制，财报仍按报告期与披露时间解读。

## 免费搜索

1. 管理员填 Tavily（首选）或 Exa（备用）凭证、当前月免费额度总额、每请求保守预留 credits、余额核验有效期与核验依据。
2. **账户必须确认免费计划、自动付费关闭、凭证专用且余额可核验、允许保存问答引用。没有证据就不要勾选开放。** 公开定价文档不能代替实际账户核验。没有接入通用账户余额查询；本地核算的前提是专用凭证且有效期内余额可信。
3. 总额包含本应用该账号本周期已经使用／预留的额度；界面展示总额减累计占用。编辑、换配置版本不会清零同账号同周期消耗。周期必须与北京时间当前月一致；不自动编造新周期免费额度。
4. Tavily 固定 basic，关闭自动参数、答案、原文与图片；Exa 固定 fast、最多 5 个结果，不请求付费摘要或正文。每次物理尝试独立占用 credits，明确拒绝最多重试一次，然后尝试另一通道。超时／结果未知保留占用并暂停通道，重新核验后由管理员保存配置解除暂停。
5. 每用户 10 次/分钟、100 次/日；额度事务预留防并发超发。没有模型预算也可使用可用免费搜索，切换 DeepSeek/Ollama 不切换来源。
6. 搜索仅从现有问答工具进入，无独立搜索门户。只从公开证券代码／证券名称字典及市场关键词提取查询；不透传原问题、账户、数量、成本或凭证。关键词无法安全提取时明确停止，不偷偷发送原文。
7. 搜索结果保留标题、链接、摘要与可取得的发布时间，不声称已读全文。正文只直连本次问题提供或实际搜索取得的公开链接；关闭个人检索后同样关闭正文读取。不再使用未经账户核验的 Firecrawl/Jina 免 Key 路径。

协议依据（2026-10-19 查阅）：[Tavily Search](https://docs.tavily.com/documentation/api-reference/endpoint/search)、[Exa Search](https://exa.ai/docs/reference/search)。真实账户、免费条件与条款尚未联调验收，默认无搜索通道开放。

## 通知

- 应用内消息默认可用，个人预算／风险／简报／小结／模型偏好事件归本人；全局预算、公共来源异常／恢复、备份失败／恢复只归唯一管理员。系统消息不带其他用户正文。
- 「我的通知」支持未读／已读、按时间倒序与查看更早消息；外部投递状态和已读独立。页头在外部渠道未配置时显示提示，可稍后完成，不阻断业务。
- 可存多条 PushPlus、邮件 SMTP 或飞书配置；同时仅一个活动渠道，所有外发共用该渠道。保存不测试、不自动启用；测试必须主动确认当前目标。
- 密钥不回显，编辑留空保留已保存凭证。旧个人飞书配置只迁一次，不覆盖已有渠道；恢复后不自动启用旧渠道。旧飞书写入／静音／测试 API 返回迁移提示，避免形成第二条外发路径。
- 每条投递冻结渠道 ID、配置版本及用户认证版本。更换渠道仅影响后续新消息；旧明确失败在原配置重试最多两次，间隔 1 分钟／5 分钟；超时／发送中进程中断标结果未知，不自动重发、不自动换渠道。
- 本人可确认旧消息重发到当前渠道，结果未知时提示可能重复送达。停用用户、关闭外发或删除渠道会阻止后续新发送。已发出的请求仍可能送达。
- 外部只发固定摘要，不发送持仓数字、交易流水、问答正文或自定义消息标题；内网链接提示仅在网络可达时可打开。
- SMTP 仅支持 TLS/465 或 STARTTLS/587，验证证书；仅向本次解析且全为公网的固定地址连接。飞书限定官方 HTTPS Webhook；PushPlus 固定官方 HTTPS 地址，不跟随重定向。
- 消息默认保留 90 天，管理员可设 1～3650 天。清理不删除独立事件去重和费用事实。
- 恢复备份保留搜索消耗、未知占用与个人关闭搜索的偏好，搜索通道暂停待核验；旧待发消息标中断，活动渠道清空，外发保持暂停。管理员确认收件人后解除全局暂停，用户重新选择渠道；旧消息只允许本人确认后手动重发。

[PushPlus 消息接口](https://www.pushplus.plus/doc/guide/api.html)仅作为协议依据，不代表真实接收人已验收。本轮所有投递验证均使用合成发送器，未向真实收件人发送。
