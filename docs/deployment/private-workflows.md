# 个人业务与账号管理

个人资产、现金流、定投、券商、自选分组、论点、提醒、问答、图片和图表均按当前登录账号访问。管理员也没有读取其他账号私人资源的入口。WebSocket 推送按本人持仓裁剪；会话撤销或失效后关闭连接。

设置页中的个人接入只保存本人的 OKX、知识星球、通知配置与 provider 凭证。公共代理、模型服务和公共数据源由管理员配置；provider 代码由部署者安装，实例和运行上下文按用户隔离，插件必须使用当前用户的配置接口，不得自行保存全局凭证或缓存。私人题材与历史补充不会写入共享行情档案。

私人接入配置保存于 `LICAI_DATA_DIR/config/users/<id>/connections.json`，文件权限为 0600。不会自动读取或认领旧的全局 Keychain／环境凭证；升级前保留旧资料，再由本人重新配置。配置只展示是否已配置或脱敏标签，没有查询凭证明文的接口。

管理员在侧边栏「管理 → 账号管理」创建普通账号、设置临时密码、重置密码、停用或启用。临时密码首次登录必须修改；最低 4 字符，建议至少 8 字符。停用撤销全部会话、关闭推送连接、取消后台任务；保留业务数据。启用不恢复旧会话，不补跑停用期间的任务或定投。仅已停用普通账号可在用户名确认后删除个人数据，费用与审计保留匿名关联；唯一管理员不可删除或停用，遗失密码使用本机恢复流程。

个人导出版本 2 包含本人的业务表，不包含认证表、公共配置、费用账本或私人接入凭证文件。图片文件不打包，不能替代完整运行目录备份。导入拒绝外部 user_id；所有数字 ID 重新分配，父子关系在同一文件内重建。`replace` 替换本人的全部个人业务，`merge` 按本人自然键合并；格式或关联无效则整次撤销。导入前使用 SQLite 一致性快照备份，文件只留在本机受保护目录。不要导入旧整库备份；整库恢复归 D02。

后台非 AI 定投、结算、组合预热／快照、收盘数据归档和通知仍按用户执行，与浏览器在线状态无关。自动 AI 默认关闭；受控模型、预算与自动 AI 设置将在 B 部分完成后开放。退出登录不取消已提交问答，停用或明确取消阻止后续步骤；已发出的远端请求尽力取消。

当前离线测试不代表 Docker、Windows、macOS 系统启动、第三方服务或真实付费模型已通过验收。D01/D02 的完整备份恢复仍须单独完成后才能按总计划开放日常使用。

权限分类见 [路由权限清单](route-permissions.md)。本机私人台账工具须明确传入账号，例如 `venv/bin/python scripts/rules.py --user-id 2` 与 `venv/bin/python scripts/tool_gaps.py --user-id 2 --clear`；本机执行者须有该运行目录的访问权限。

## 设置与管理入口

所有账号的「设置」保留本人用量、AI 与搜索偏好、通知渠道、OKX、知识星球及个人扩展凭证。管理员侧边栏额外显示「管理」分组，包含账号管理、模型服务、用量与预算、数据与搜索、系统配置、备份与维护；普通账号直接打开管理链接也不会加载管理表单，后端继续独立检查权限。

个人扩展凭证清除使用 `DELETE /api/settings/provider?credentials_only=true`，管理员也只清除本人凭证。管理页卸载插件沿用不带参数的删除请求；普通账号无法卸载全局插件。更新后需重启后端再使用新的个人凭证清除入口。
