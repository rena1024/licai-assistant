# 持仓、交易与其他资产归属（A04）

A04 已完成持仓资产范围的账号隔离。完整多用户版本仍待 A05～A10，当前开发分支尚不适合多人日常使用。

## 已实现的行为

- 持仓、持仓操作、交易日志、其他资产及其操作、资产快照、早盘简报均绑定 `user_id`。
- 不同账号可以独立持有同一股票；读取、修改、清仓、合并和删除仅作用于本人数据。通过他人的资源 ID 操作时返回 404，避免暴露资源是否存在。
- 后端从有效会话取得身份，不采用请求正文中的 `user_id`。数据库私有函数要求显式传入身份；未设置身份的服务调用直接失败，不默认使用管理员。
- 资产操作以复合外键校验父资产及其归属。与其他资产关联的定投计划通过父资产归属限制访问；定投表及其他个人设置的完整归属仍由 A05 完成。
- 持仓分析、今日收益、风险、事件、持仓资讯等直接依赖持仓的缓存按账号区分；公开行情缓存继续共享。相同股票的简报也按账号保存，防止共享成本或私人正文。

## 数据库升级保护

账号结构仍为 `account_schema_version=1`，资产结构独立记录 `portfolio_schema_version=1`。
启动时，旧的无归属资产表只有在为空时才会重建；已有账号和会话保留。
发现非空的无归属资产表会在写入前停止，不自动认领、清空或分配给管理员。
请保留旧库，显式指定新的空 `LICAI_DATA_DIR` 测试；本阶段不提供历史业务自动迁移。

## 当前阶段限制

个人后台行情监控、简报、定投、曲线预热／快照、收盘小结及规则挖掘暂时等待 A09／A10 的用户分发，启动时有明确提示。
WebSocket 认证和心跳仍可用，个人数据推送尚未恢复；公共数据预热继续运行。

旧版整表 JSON 导入会返回 409，避免覆盖其他账号或尚未隔离的配置，待 A08 完成个人归属和 ID 校验后恢复。
当前导出只包含本人上述七张资产表，元数据声明 `scope=portfolio_assets_only`、`complete_backup=false`，不能作为完整备份或恢复文件。
旧版 `scripts/seed_demo.py` 整库演示／恢复命令也已暂停。测试请使用独立空目录和页面录入的合成数据。

离线区间收益脚本须显式提供账号 ID，例如 `python scripts/interval_pnl.py 2026-10-01 --user-id 1`；该本机脚本应由部署机器维护者运行。

## 手动验证与回归

在独立测试运行目录中，用两个测试账号分别添加相同股票和不同成本，切换账号确认各自持仓、资产、收益及简报独立。
尝试用另一账号的操作／资产 ID 修改、删除或合并，应得到 404；正常本人操作仍可完成。
账号创建方式和当前入口见[账号说明](accounts.md)。

```bash
venv/bin/python -m pytest tests/test_ownership_portfolio.py -q
venv/bin/python -m pytest -q
npm --prefix frontend test -- --run
npm --prefix frontend run build
```

离线测试只用隔离数据库、合成账号及伪造外部数据，不读取真实凭证或发送请求。
完整证据见 [A04 验收记录](../../tasks/evidence/a04.md)。
