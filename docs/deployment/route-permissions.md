# HTTP 与推送权限清单

| 入口 | 访问要求 | 服务端资源边界 |
| --- | --- | --- |
| `/api/app-version`、静态页面与资源 | 公开 | 仅应用版本与公共前端文件 |
| `/api/auth/bootstrap/status`、`/bootstrap` | 本机一次性凭据；完成初始化即关闭创建入口 | 事务保证唯一管理员，不认领旧数据 |
| `/api/auth/login` | 正确账号密码、来源检查 | 只替换当前设备会话 |
| `/api/auth/me`、`/logout`、`/password` | 有效会话；写操作另需 CSRF、Origin 检查 | 固定 30 天；退出仅撤当前会话，改密撤销全部旧会话 |
| `/api/admin/users` 及子路径 | 管理员 | 只允许普通账号创建、临时密码重置、停用／启用；无角色提升或永久删除 |
| `/api/settings/llm*`、`/proxy*`、`/tdx*` | 管理员 | 公共模型服务、网络代理与公开来源配置 |
| `/api/settings/provider` | 已登录；改变或卸载公共代码配置须管理员 | 用户只保存／清除本人凭证，实例和错误状态按 owner |
| 其他 `/api/settings/*` | 已登录 | 风险、通知、知识星球、规则等按本人归属 |
| `/api/data/export`、`/import` | 已登录；导入需 CSRF、Origin | 固定个人业务表白名单；拒绝认证、公共配置和费用账本；服务端指定身份、重新映射关联 ID |
| `/api/ask/*` 与图片、图表 | 已登录 | 会话、消息、运行记录、媒体、工具结果均只属于本人 |
| 其余 `/api/*` 业务路由 | 统一有效会话；临时密码门禁；写操作需 CSRF、Origin | 个人资源在 CRUD／服务层检查 owner，不能用猜中的资源 ID 访问他人；公共报价可复用 |
| `/ws` | 同源、有效会话且已修改临时密码 | 连接绑定用户和会话；推送前及心跳重查，私有字段／本人持仓代码只发 owner，失效关闭 |

匿名 HTTP 矩阵遍历应用实际注册的所有业务路由，在路由参数验证之前要求登录；管理员管理和公共配置另有普通用户拒绝用例。后台任务携带独立用户上下文，不依赖 HTTP 连接，也不采用匿名或默认管理员身份。
