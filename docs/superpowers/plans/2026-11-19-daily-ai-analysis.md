# 页面 AI 分析每日首次访问生成

**目标：** 每个账号、每项分析及参数在北京时间每天首次访问时自动生成一次；之后展示已保存结果，只有“重新生成”会再次生成。

**范围：** 市场情绪、板块趋势、资讯摘要、今日组合归因、交易纪律复盘、榜单结构复核。行情及其他确定性数据照常刷新；早盘简报、手动问答和点击新闻后启动的解读不改变。

**方案：** 复用现有后台共享任务，在用户独立的 `user_settings` 中保存每日尝试状态和结果。按分析函数及参数区分，结果覆盖保存而非每天新增记录。失败及服务重启遗留任务不随切页重试；手动重新生成可重试，并更新当天快照。前端缓存改为北京时间自然日，补齐各分析的重新生成入口。
