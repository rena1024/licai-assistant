# 基金历史记录导入实施计划

> 执行方式：在当前会话逐项实现并验证，不改动已有未提交工作。

## 已确认规则

- 使用现有 `external_assets`（FUND）和 `external_asset_actions`，默认读取 `position`，平台为支付宝。
- 定投买入、用户买入、用户跨 TA转换、用户转换均计为买入；确认金额含手续费，净值由净申购金额除以确认份额推算。
- 营销买入只增加份额，不增加投入；机构分红均为现金分红；用户卖出手续费为零。
- 只导入现有五年记录，不伪造期初持仓。提示份额、成本及盈亏尚待历史补齐，允许后续补入更早记录并重算。
- 采用独立命令行工具，复用现有备份、运行目录、用户隔离和基金账本。默认只读预览，`--apply` 才写入。
- 保留订单号、原始业务及确认日期等来源信息到流水备注，使用订单号去重；同订单内容冲突整次拒绝。
- 对同用户、同平台、同代码的重复资产或无法核对的旧流水拒绝自动合并，不覆盖人工记录。
- 用户确认：一笔确认金额为零、确认份额为正的异常分红暂不导入，使用显式 `--exclude-order` 参数排除，原 Excel 不变。

## 重点核对

订单号精度丢失应拒绝；基金代码补零；赎回不可重复扣费；零成本赠送不能产生虚构投入；重复订单不能因排序或行号变化再次入账；后补的旧交易须按历史顺序重算。
