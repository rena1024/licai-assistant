## 工程决定

- 无新增运行依赖，保留既有架构；数据库新增版本化表，不清空或重新分配已有用户数据。
- 搜索额度必须有实际专用账户证据；公开 API 文档不代表账户免费资格。配置中的总额包含同账号本周期已有消耗，未知占用不退还。
- 原 Firecrawl/Jina 免 Key 路径缺少免费条件核验，改为只直连原网站正文；失败不声称已读全文。
- 缺价不能进入实时推送算术或完整日估值快照；不可信缓存不以成本价或零价补齐。
- 恢复不回退搜索消耗与关闭偏好，不重新外发旧通知；清空活动渠道并持久暂停外发，需确认配置后重新启用。
