# A04 验收记录：持仓、交易与其他资产归属

日期：2026-10-16。实现提交：`6e107af`。分支：`codex/p0-foundation-protection`。

## 实现与验收范围

七张表增加强制 `user_id`：`holdings`、`position_actions`、`trade_log`、`external_assets`、`external_asset_actions`、`portfolio_snapshots`、`morning_briefings`。
持仓及简报采用包含账号的唯一约束；快照使用账号与日期的联合主键；资产操作使用账号与父资产 ID 的复合外键。
相关数据库函数强制显式身份，HTTP 身份源于验证后的会话，经请求局部 ContextVar 传递至现有服务，再显式传入数据库；生产代码不设置匿名或默认管理员身份。

持仓、其他资产及其操作的增删改查、合并／清仓、相关派生服务和脚本调用均已更新。
依赖这些数据的私有缓存按账号区分；公开行情数据可共享，追加私人注释前复制公共资讯对象。
关联资产的定投访问先检查父资产归属，防止当前账号执行时暂停或修改其他账号的定投；A05 仍须完成定投表及其他个人设置归属。

`portfolio_schema_version=1` 与账号版本分开。空的旧资产表可重建并保留账号；非空无归属历史表在写入前拒绝，验证数据库文件保持不变。初始化重复执行保持幂等。
